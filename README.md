# NavisLabs Website

NavisLabs is a multi-product AI company site built with Next.js 16, React 19, and Tailwind CSS v4.

## What’s in the site

- A clean homepage that introduces the company and its product family
- Dedicated product pages for `HireAI` and `Navis AI`
- A company page with the brand story and operating principles
- Shared navigation, footer, and waitlist entry points

## Run locally

```bash
npm install
npm run dev
```

## Key routes

- `/` - homepage
- `/products` - product overview
- `/products/hireai` - live product page
- `/products/navis-ai` - product-in-development page
- `/company` - company story
